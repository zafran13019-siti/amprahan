💡 Panduan Regex
• Gunakan (...) untuk menangkap grup yang diinginkan
• NIP: NIP\s*:\s*(\d{18})
• Nama: Nama\s*:\s*([A-Z][A-Z\s,\.]+)
• Angka: ([\d.,]+)
• Uji regex Anda di regex101.com

📖 Cara Penggunaan
  1. Upload PDF: Buka menu "Upload PDF" dan drag & drop file PDF rekap tukin dari absensi.kemenag.go.id
  2. Proses File: Klik tombol "🚀 Proses Semua File" untuk mengekstrak data dari PDF
  3. Lihat Rekap: Buka menu "Rekap Data" untuk melihat hasil ekstraksi dalam bentuk tabel
  4. Edit Manual: Aktifkan "Mode Edit" untuk mengedit data langsung di tabel
  5. Export: Klik "📥 Export Excel" untuk menyimpan hasil rekap dalam format .xlsx
📝 Format PDF yang Didukung
Script ini dioptimalkan untuk PDF rekapitulasi tunjangan kinerja dari absensi.kemenag.go.id dengan format:
  • Header: Nama, NIP, Jabatan, Grade
  • Rekapitulasi: Tunjangan Kinerja, Potongan Telat, PSW, dll
  • Tabel Data Kehadiran harian
